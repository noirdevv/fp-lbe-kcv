# SeraSi: Analisis Estetika Website Menggunakan Ekstraksi Fitur CNN Berbasis Linear Regression dan KNN

### ✨ https://luntanglantung.streamlit.app/ ✨

## Prominent Features
1. **Ekstraksi Fitur Multimodal Hibrida**
   - Penyematan Visual Mendalam (Deep Visual Embeddings)
   - Tingkat Kecerahan Warna Hasler–Süsstrunk (Colorfulness)
   - Distribusi 16 Palet Warna W3C
   - Analisis Simetri & Keseimbangan Spasial
   - Kompleksitas Dekomposisi Quadtree
   - Segmentasi Area Tata Letak

2. Artefak Model 
   - `pca_transformer.pkl`: Model transformasi PCA
   - `hybrid_scaler.pkl`: Penskala data fitur
   - `ml_model.pkl`: Model regresi terlatih

## Tech Stack
- **Frontend & Web Framework**: Streamlit
- **Computer Vision & Image Processing**: OpenCV (opencv-python), Pillow (PIL)
- **Machine Learning & Preprocessing**: Scikit-Learn (sklearn), SciPy (scipy.spatial)
- **Pengolahan Data & Serialisasi**: Pandas, NumPy, Joblib

## Dataset Training Model
Sumber Dataset: [Datasets on Website Aesthetics for Machine Learning](https://github.com/calista-ai/website-aesthetics-datasets?utm_source=chatgpt.com)
